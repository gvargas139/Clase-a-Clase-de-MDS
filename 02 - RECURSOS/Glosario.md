# Glosario del módulo

[[00 - INICIO|← Inicio]]

| Término | Definición contextual | Primera ficha sugerida |
|---|---|---|
| **Metodología de desarrollo** | Conjunto de métodos para organizar el trabajo de construcción de software. | [[01 - CLASES/01 - Introduccion y evolucion|01]] |
| **Ciclo de vida** | Etapas por las que pasa un producto de software desde su planificación hasta el mantenimiento. | [[01 - CLASES/02 - Modelos de procesos|02]] |
| **Modelo en cascada** | Enfoque secuencial que distingue fases con objetivos específicos. | [[01 - CLASES/02 - Modelos de procesos|02]] |
| **Modelo V** | Modelo que vincula actividades de desarrollo y verificación/validación. | [[01 - CLASES/02 - Modelos de procesos|02]] |
| **Iteración** | Repetición de un ciclo de trabajo para revisar y mejorar un resultado. | [[01 - CLASES/03 - Enfoques y metodologias|03]] |
| **Incremento** | Porción de funcionalidad añadida al producto en una entrega sucesiva. | [[01 - CLASES/03 - Enfoques y metodologias|03]] |
| **Scrum** | Enfoque ágil de trabajo organizado por ciclos cortos. | [[01 - CLASES/03 - Enfoques y metodologias|03]] |
| **XP** | Enfoque ágil basado en prácticas de programación y retroalimentación. | [[01 - CLASES/03 - Enfoques y metodologias|03]] |
| **RUP** | Proceso Unificado de Rational, estructurado por fases y orientado a casos de uso y arquitectura. | [[01 - CLASES/04 - RUP concepcion|04]] |
| **Artefacto** | Producto o documento que registra un resultado del trabajo de desarrollo. | [[01 - CLASES/05 - RUP fases y artefactos|05]] |
| **Requisito funcional** | Comportamiento o función que debe proporcionar el sistema. | [[01 - CLASES/06 - Cascada requisitos|06]] |
| **Requisito no funcional** | Propiedad o restricción del sistema, como seguridad o rendimiento. | [[01 - CLASES/06 - Cascada requisitos|06]] |
| **UML** | Lenguaje de modelado principalmente gráfico para describir sistemas. | [[01 - CLASES/07 - Cascada diseno y UML|07]] |
| **Caso de uso** | Descripción de una interacción para lograr el objetivo de un actor. | [[01 - CLASES/07 - Cascada diseno y UML|07]] |
| **Implementación** | Traducción del diseño y sus especificaciones a código. | [[01 - CLASES/08 - Cascada implementacion|08]] |
| **Prueba de software** | Evaluación del comportamiento para detectar discrepancias respecto de lo esperado. | [[01 - CLASES/09 - Cascada pruebas|09]] |
| **Mantenimiento** | Cambios y actualizaciones posteriores a la entrega para corregir, prevenir, mejorar o adaptar. | [[01 - CLASES/10 - Cascada despliegue y mantenimiento|10]] |

*Las definiciones están resumidas y redactadas para fines didácticos a partir de los contenidos del módulo.*
